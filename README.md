# Trailer Cut & Insert Script 🎬

Скрипт на Python для автоматической нарезки фильмов и вставки рекламных роликов (или любых других видео) по заданному расписанию (таймингам). 

Главное преимущество: скрипт работает на базе **FFmpeg** и склеивает видео в режиме `-c copy` (по возможности), что позволяет собирать многочасовые трейлеры за считанные секунды **без потери качества и без долгой перекодировки**.

## 🚀 Возможности
- **Пакетная обработка**: можно сгенерировать сразу несколько разных трейлеров из одного или нескольких фильмов за один запуск.
- **Удобный конфигурационный файл** в формате YAML.
- Поддержка форматов времени как с двоеточиями (`00:05:30`), так и с точками (`00.05.30`).
- Автоматическая очистка временных файлов (огрызков видео) после успешной склейки.

## 📦 Требования
Для работы скрипта понадобятся:
1. **Python 3.6** или новее.
2. Библиотека **PyYAML** (для чтения файла конфигурации).
3. Утилита **FFmpeg** (должна быть установлена в системе).

## 🛠 Установка

### Для macOS / Linux:
1. Установите FFmpeg (на Mac это проще сделать через Homebrew):
   ```bash
   brew install ffmpeg
   ```
2. Установите библиотеку PyYAML:
   ```bash
   pip3 install pyyaml
   ```

### Для Windows:
1. Установите [Python](https://www.python.org/downloads/) (при установке обязательно поставьте галочку **"Add Python to PATH"**).
2. Скачайте `ffmpeg.exe` с [официального сайта](https://ffmpeg.org/download.html) (или GitHub) и положите этот файл в ту же папку, где находится скрипт.
3. Устанавливать PyYAML вручную не обязательно: просто запустите `start.bat`, и он попытается скачать нужные библиотеки сам.

## ⚙️ Настройка (config.yaml)

Вся логика нарезки описывается в файле `config.yaml` (если его нет в папке, скрипт при первом запуске создаст красивый демо-шаблон).

Пример структуры `config.yaml`:
```yaml
- output: trailer_1.mkv
  movie: Наполеон_2023_WEB-DLRip-AVC.mkv
  sequence:
    - 00.00.00-00.05.10
    - ad_banner_1.mp4
    - 00.05.10-00.10.20

- output: trailer_2.mkv
  movie: Наполеон_2023_WEB-DLRip-AVC.mkv
  sequence:
    - ad_banner_1.mp4
    - 00.15.00-00.20.00
    - ad_banner_2.mp4
    - 01.10.00-01.15.00
```

### Как это работает:
Каждый блок в массиве (`-`) — это одно итоговое видео.
* **`output`** — имя файла, который получится на выходе.
* **`movie`** — исходный фильм, который мы будем нарезать.
* **`sequence`** — последовательность (читается сверху вниз):
   * **Тайминг** (`Начало-Конец`): скрипт вырежет этот фрагмент из `movie`. Можно использовать слово `end`, чтобы вырезать до самого конца фильма (например: `01.10.00-end`).
   * **Путь к файлу** (`ad_banner_1.mp4`): скрипт просто добавит этот ролик в очередь на склейку в данном месте.

## ▶️ Запуск

### Через терминал (универсально):
```bash
python cut_and_insert.py -c config.yaml
```

### На Windows (в 1 клик):
Дважды кликните по файлу **`start.bat`**.

## 💡 Важные советы для идеальной склейки
Чтобы склейка (конкатенация) видео проходила гладко, без "заиканий" плеера и рассинхрона звука:
* Рекламные ролики желательно подготавливать (рендерить) с теми же параметрами **разрешения** (например, 1920x1080) и **частоты кадров** (FPS, например 24 или 23.976), что и у главного фильма.
